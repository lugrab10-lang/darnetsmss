# مشروع تطبيق الدار نت (Al-Dar Net App)

تطبيق مخصص لشبكات المايكروتك والوايرلس (الهوتسبوت) مع دعم الإشعارات بدون تسجيل دخول للمستخدم.

---

### طريقة استخراج ملف APK جاهز في دقيقتين عبر GitHub (مجاناً وبدون أي برامج على جهازك):

1. **إنشاء حساب في GitHub:**
   - افتح موقع [github.com](https://github.com) وسجل حساباً مجانياً إذا لم يكن لديك حساب.

2. **إنشاء مستودع جديد (Repository):**
   - اضغط على زر **New Repository**.
   - سمّه مثلاً: `aldar-net-app`.
   - اختر **Public** أو **Private**.

3. **رفع ملفات هذا المشروع:**
   - فك الضغط عن ملف `al_dar_net_app_project.zip`.
   - اسحب الملفات وضعها داخل المستودع في GitHub (Upload files) ثم اضغط **Commit changes**.

4. **تحميل ملف APK تلقائياً:**
   - توجه إلى تبويب **Actions** في أعلى المستودع.
   - ستجد أن البناء يعمل تلقائياً (`Build Al-Dar Net APK`).
   - بعد انتهاء البناء (أيقونة خضراء ✔️)، اضغط على البناء ثم حمّل ملف:
     `Al-Dar-Net-Release-APK`
   - ثبّت الملف مباشرة على هواتف الأندرويد!
